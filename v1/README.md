# Финальный лендинг «Праксеология менеджмента» — направление «Балтика» (26.09.2026)

Открыть: `index.html` двойным кликом. Страница офлайн: шрифты (Geist, Spectral) и фото лежат в `assets/`, внешних запросов нет.

Просмотр версий без квиза: `index.html?exp=first|been&sphere=manager|owner|artist`. Квиз заново: `index.html?quiz=1` (или ссылка «изменить» на первом экране).

## Из чего собрано

- **Текст** — `COPY.md`, написан скиллом na-pero (продающий режим, правила «Лендинг: визуальное повествование»: фильтр пользы, раскладка экранов, нет материала — нет экрана) по материалам проекта: ТЗ `../traditsiya-baltika/TZ-i-kopirayt.md`, BLUEPRINT, аудит фактов H-PROOF, голос аудитории, тезисы разделов 1 и 4. Сканер: 0 нарушений во всех шести версиях. Каждая версия страницы — 424–448 слов (прошлый заход — около 1 000). Биография ведущего сверена с orlov.academy/ontom. В конце `COPY.md` — заметки и что уточнить у заказчика.
- **Дизайн** — токены направления «Балтика» из ТЗ (кремовый, тёплый светлый, сосновый, морской сланец, песок, акцент #D4572A точечно) и шрифтовая пара из прошлого захода `../eksperiment-sfer/` (Geist + Spectral Light — у шрифтов референса нет кириллицы). Уроки прошлого захода учтены: фоны статичные, без видео; рукописных овалов нет; цена не на первом экране.
- **Сборка** — `python3 build.py`: подставляет `COPY.md` в `template.html` и пишет `index.html`. Правка текста — в `COPY.md`, потом пересборка.

## Порядок экранов

Квиз (опыт, сфера) → первый экран своей сферы → вступление → полоса фактов (даты, место, формат, цена со скидкой) → как устроена игра (для впервые) или что нового (для бывших) → триптих (для впервые) → что вы будете делать → что меняется → с чем приезжать → ведущий → участие → вопросы → финальный призыв → подвал с атрибуцией фото.

## Подписи вне COPY.md

Служебные подписи интерфейса взяты из ТЗ или названий блоков: пункты меню, надзаголовки блоков («Как устроена игра», «На игре», «Что меняется», «С чем приезжать», «Ведущий», «Участие», «Вопросы»), «Страница собрана для: … изменить», «Пропустить и читать всё подряд», метка «вы здесь» у третьей части триптиха.
